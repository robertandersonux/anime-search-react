# Anime Search

A React app for finding anime series. Search by title, filter by release year, browse a list of top picks, and open any title for its full plot, rating and details.

**Live:** https://robertandersonux.github.io/anime-search-react/

![Anime Search logo](./ANIME_SEARCH.png)

## Features

- Search anime series by title, with a minimum release year filter
- Top Anime tab with hand-picked classics
- Detail view with poster, plot and ratings, pulled from the OMDb API
- Animated loading screen while results come in

## Built with

React · JavaScript · CSS · OMDb API · GitHub Pages

## About this repo

This branch holds the built site that GitHub Pages serves. The React source code (components for the navbar, hero, results grid, detail view and footer) is not in this repo yet.
